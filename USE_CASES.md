# DebateChecker – Use Cases & Tips

## 📚 For Students

### Before You Submit Your Essay
1. Write your essay normally
2. Copy each main argument into DebateChecker
3. Fix any fallacies found
4. Check evidence strength
5. Submit improved version
6. **Result:** Better grades guaranteed

### Example
```
Your argument: "Social media is bad because everyone uses it"
DebateChecker: "Hasty Generalization - just because everyone uses it doesn't mean it's bad"
Fixed: "Research shows social media has negative effects on mental health for 40% of users"
```

### Common Student Arguments to Test
- Thesis statements
- Main body paragraphs
- Counter-argument rebuttals
- Conclusion summaries

## 🎤 For Debaters & Public Speakers

### Before Your Speech
1. Write main talking points
2. Test each point for fallacies
3. Prepare counter-arguments
4. Add more evidence if needed
5. Practice with strong arguments
6. **Result:** Win debates easily

### Example
```
Weak opening: "Everyone knows climate change is real"
DebateChecker: "Appeal to common belief - need facts"
Strong opening: "97% of climate scientists agree on human-caused climate change based on 40+ years of research"
```

### Speaking Tips
- Test one main idea at a time
- Add statistics and research
- Avoid "everyone agrees" statements
- Prepare rebuttals for weak points


## 10 Tips to Get Better Results

### Tip 1: Be Specific
❌ "This is bad"
✅ "This reduced efficiency by 25%"

### Tip 2: Use Data
❌ "Most people agree"
✅ "72% of respondents in a 2024 survey agree"

### Tip 3: Avoid Absolutes
❌ "Everyone should do this"
✅ "Research suggests most people benefit from"

### Tip 4: Name Your Sources
❌ "Scientists say"
✅ "Harvard researchers discovered"

### Tip 5: Show the Connection
❌ "A happened then B happened, so A caused B"
✅ "Research shows A causes B through mechanism X"

### Tip 6: Acknowledge Limits
❌ "This always works"
✅ "This works in 80% of cases studied"

### Tip 7: Don't Attack People
❌ "You're an idiot"
✅ "This specific claim lacks evidence"

### Tip 8: Prepare Counters
❌ Just make your point
✅ Anticipate objections and address them

### Tip 9: Use Examples
❌ "Stress is bad"
✅ "Chronic stress increases cortisol by 40%, leading to anxiety"

### Tip 10: Test Multiple Versions
Try different versions of your argument to find the strongest one

## Common Fallacies Explained Simply

### Ad Hominem (Attacking the Person)
```
❌ "You're wrong because you're stupid"
✅ "This argument lacks evidence because..."
```

### Hasty Generalization (One Example = All)
```
❌ "I know someone who smokes and lived to 90, so smoking is safe"
✅ "While some smokers live long lives, 90% of smokers die younger than average"
```

### False Cause (After = Because)
```
❌ "I wore lucky socks and won, so socks cause winning"
✅ "I practiced more and improved my skills, which led to winning"
```

### Appeal to Authority (Expert Said It)
```
❌ "A celebrity said so, so it must be true"
✅ "Three peer-reviewed studies show..."
```

### False Dilemma (Only 2 Choices)
```
❌ "Either you're with us or against us"
✅ "There are multiple perspectives on this issue"
```

### Circular Reasoning (Using Conclusion as Proof)
```
❌ "This is true because I said it's true"
✅ "This is true because these facts prove it"
```

## Quick Improvement Checklist

After DebateChecker shows results, check:

- [ ] Did I use specific numbers/data?
- [ ] Did I avoid attacking the person?
- [ ] Did I use one example to prove everything?
- [ ] Did I name my sources?
- [ ] Can someone easily argue against me?
- [ ] Am I assuming things without proof?
- [ ] Did I address counter-arguments?
- [ ] Am I using emotions or facts?

The more checkboxes you tick, the stronger your argument!
