## What is DebateChecker?

**DebateChecker** is a free, intelligent web application that analyzes arguments and claims to help users communicate more persuasively. It uses pattern recognition and linguistic analysis to identify logical fallacies, evaluate evidence strength, suggest counter-arguments, and provide actionable recommendations for improvement.

Simply paste your argument, claim, or viewpoint into the tool, and receive instant feedback on:
- Logical fallacies present in your reasoning
- Quality and quantity of evidence provided
- Potential counter-arguments you haven't considered
- Hidden assumptions underlying your claim
- Specific recommendations to strengthen your position
- An overall assessment score

## Key Features

### 🚫 Logical Fallacy Detection
Identifies 8+ common logical fallacies that weaken arguments:

| Fallacy | What It Is | Impact |
|---------|-----------|--------|
| **Ad Hominem** | Attacking the person instead of their argument | Destroys credibility |
| **Appeal to Authority** | Using authority without questioning relevance | False reasoning |
| **Hasty Generalization** | Drawing broad conclusions from limited examples | Weak evidence |
| **False Cause (Post Hoc)** | Assuming B caused A because B happened after A | Flawed causation |
| **False Dilemma** | Presenting only 2 options when many exist | Limited perspective |
| **Circular Reasoning** | Using conclusion to support premise | No actual proof |
| **Straw Man** | Misrepresenting opponent's position | Dishonest argument |
| **Appeal to Emotion** | Using feelings instead of logic to persuade | Manipulation |

**Severity Levels:** High (critical), Medium (important), Low (minor)

### 📊 Evidence Assessment
Analyzes the quality and quantity of evidence:
- **Counts** how many evidence claims are present
- **Rates quality** from None → Limited → Moderate → Substantial
- **Calculates strength score** (0-100%) based on evidence + fallacies
- **Visual progress bar** shows argument strength at a glance

### ⚔️ Counter-Arguments
Suggests opposing viewpoints and perspectives you haven't considered:
- Identifies universal claims that might have exceptions
- Points out where anecdotal evidence isn't generalizable
- Questions assumptions presented as facts
- Recommends adding specific evidence
- Suggests acknowledging limitations

### 🔍 Underlying Assumptions
Reveals hidden assumptions that your argument depends on:
- "Assumes there is no alternative approach"
- "Assumes direct causal relationship"
- "Assumes uniformity across all cases"
- "Assumes past patterns continue unchanged"
- "Presents possibilities as certainties"

Understanding assumptions helps strengthen your position by explicitly justifying them.

### 💡 Recommendations
Provides actionable, specific feedback to improve your argument:
1. Address identified logical fallacies
2. Add empirical evidence or concrete data
3. Make assumptions explicit and justify them
4. Test against opposing viewpoints
5. Acknowledge limitations and counter-arguments

### 📈 Overall Assessment
Provides a comprehensive summary:
- **Argument Strength Rating:** Strong / Moderate / Weak / Very Weak
- **Personalized Assessment Text:** Explains the rating and next steps
- **Actionable Feedback:** Clear guidance on improvement priorities

## How to Use DebateChecker

### Step 1: Visit the Website
Open DebateChecker in any web browser. No login, registration, or installation required.

### Step 2: Enter Your Argument
Click the text area that says "Enter your claim or argument:" and paste or type:
- A claim you want to validate
- An argument you're making
- A position you're defending
- A statement you want to test
- Any debatable claim

**Example Input:**
```
Everyone who exercises regularly lives past 100 because my grandfather 
exercised daily and lived to 101.
```

### Step 3: Click "Analyze Argument"
Press the purple "Analyze Argument" button. The tool processes your input instantly.

### Step 4: Review the Results
Your analysis appears immediately with 6 detailed sections:

#### **🚫 Logical Fallacies Detected**
- Lists each fallacy found
- Explains why it's a problem
- Shows severity level (High/Medium/Low)
- Fallacy count badge at the top
- Green checkmark if no fallacies found

#### **📊 Evidence Assessment**
- Evidence provided: Shows number of claims
- Evidence quality: Rates the type of evidence
- Strength score: Visual progress bar (0-100%)
- Red if weak, yellow if moderate, green if strong

#### **⚔️ Potential Counter-Arguments**
- 2-3 opposing viewpoints
- Specific challenges to your position
- Points you haven't considered
- Helps you prepare for debate

#### **🔍 Underlying Assumptions**
- 2-3 hidden assumptions revealed
- What your argument depends on
- Asks: "Is this really true?"
- Helps strengthen logical foundation

#### **💡 Recommendations**
- 4 actionable improvement steps
- Prioritized by impact
- Specific and practical
- Tells you exactly what to do next

#### **📈 Overall Assessment**
- Argument strength badge (color-coded)
- Personalized assessment text
- Explains why you got this rating
- Next steps for improvement

### Step 5: Improve Your Argument
Use the feedback to:
- Eliminate logical fallacies
- Add specific evidence
- Address counter-arguments
- Justify your assumptions
- Refine your position

### Step 6: Test Again (Optional)
Click "Clear" to start fresh, or submit an improved version to see your score increase.

### Core Analysis Engine (`src/utils/argumentAnalyzer.js`)

The heart of DebateChecker. Contains functions:

```javascript
analyzeArgument(argument)           // Main analysis function
detectFallacies(argument, lowerArg) // Identifies logical fallacies
countEvidenceClaims(argument)       // Counts evidence provided
assessEvidenceQuality(...)          // Rates evidence quality
generateCounterArguments(...)       // Suggests opposing views
extractAssumptions(...)             // Finds hidden assumptions
generateRecommendations(...)        // Creates improvement suggestions
calculateStrengthScore(...)         // Calculates 0-100 score
getOverallScore(strengthScore)      // Returns Strong/Moderate/Weak/Very Weak
getAssessmentText(...)              // Creates personalized feedback
```

### Extending the Tool

#### Add More Fallacy Detection

Edit `src/utils/argumentAnalyzer.js`, in the `detectFallacies()` function:

```javascript
// Add a new fallacy pattern
if (/pattern-to-match/i.test(argument)) {
  fallacies.push({
    name: 'Fallacy Name',
    description: 'Explanation of the fallacy',
    severity: 'High' // or 'Medium' or 'Low'
  })
}
```

#### Improve Analysis

Refine regex patterns, adjust scoring weights, or add new analysis dimensions:

```javascript
// In calculateStrengthScore()
score -= highSeverityFallacies * 20  // Increase weight
score += evidenceCount * 5            // Adjust scoring formula
```

#### Add New UI Features

Add components in `src/components/`, import them in `App.jsx`.
